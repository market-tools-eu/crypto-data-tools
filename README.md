# crypto-data-tools

Набор инструментов для загрузки и анализа биржевых данных: выгрузка
котировок через API, расчёт статистики по историческим данным, ведение
журнала событий с отслеживанием исходов.

Написано на Python, без внешних зависимостей кроме `ccxt`.

---

## Состав

### `ohlcv_download.py` — выгрузка котировок с биржи

Скачивает исторические свечи за произвольный период через `ccxt`.

- Любой период по датам, а не «последние N дней»
- Таймфреймы от 1m до 1d, выбор через аргумент
- Постраничная догрузка с обработкой обрывов связи и повтором запроса
- Компактный формат хранения: свечи списками, а не словарями —
  файл выходит примерно вчетверо меньше

```bash
python ohlcv_download.py 2025-01-01 2025-04-01 tf=1h out=data.json BTC/USDT ETH/USDT
```

```
период: 2025-01-01 → 2025-04-01 (90 дней), монет: 2, ТФ: 1h
BTC/USDT: качаю 1h...
    готово: 2160 свечей, 2025-01-01 → 2025-03-31
ETH/USDT: качаю 1h...
    готово: 2160 свечей, 2025-01-01 → 2025-03-31

Сохранено в data.json (0.4 МБ), монет: 2
```

### `market_stats.py` — статистика по историческим данным

Считает три группы показателей по выгруженным котировкам.

1. **Распределение по времени** — в какие часы и дни чаще всего
   формируются экстремумы периода
2. **Серии** — как часто за N однонаправленными интервалами следует
   разворот
3. **Пробои уровней** — доля истинных и ложных пробоев предыдущих
   максимумов и минимумов

```bash
python market_stats.py data.json
```

```
3. ПРОБОЙ ВЧЕРАШНИХ HIGH/LOW
вверх: проколов 523 из 1095 дней (48%)
   истинных 171 (32.7%) | ложных 352 (67.3%)
вниз: проколов 466 из 1095 дней (43%)
   истинных 121 (26.0%) | ложных 345 (74.0%)
```

### `event_logger.py` — журнал событий с отслеживанием исходов

Пассивный логгер: записывает события в CSV и на последующих проходах
дописывает, чем они закончились.

Запись делается в момент обнаружения события, исход дописывается позже —
поэтому статистика получается честной: подогнать её задним числом нельзя.

- Не вмешивается в работу основной программы: весь вызов обёрнут так,
  что любая внутренняя ошибка гасится и не может уронить вызывающий код
- Дедупликация: одно открытое событие на объект
- Сводка по накопленному одной командой

```bash
python event_logger.py
```

---

### `ohlcv_load.py` — чтение и пересборка таймфреймов

Вспомогательный модуль. Терпим к формату входных данных: понимает
свечи и списками, и словарями, время в секундах и миллисекундах.
Пересобирает младший таймфрейм в старший, отбрасывая неполный
последний бар.
